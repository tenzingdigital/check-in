`terms_version` a customer accepted, so the file they agreed to has to stay
exactly as it was on the day they clicked. To change the wording, add a new
dated file, publish it, and only then start recording the new version at signup.

## Before these go live

Drafted in-house and **not yet reviewed by a solicitor**. Three clauses are the
ones to have looked at, because they are the ones that cost money if wrong:

1. **Liability cap** (Terms section 9). Currently fees paid in the preceding
   twelve months, with data protection liability sitting under it. A customer's
   solicitor may push for a separate, higher cap on data protection claims.
2. **Trial data lifecycle** (Terms section 2, DPA section 9). Read-only for
   thirty days, then deleted. Check the notice we give before deletion is
   adequate, given the data may be a register the customer is audited on.
3. **International transfers** (DPA section 6). Both sub-processors are
   US-incorporated with EU data residency. Obtain and file Render's and Resend's
   own DPAs and Standard Contractual Clauses, and complete a transfer impact
   assessment, before claiming this position to a customer.
